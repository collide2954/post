A modern chat app in the spirit of IRC.

Post is simple, open, and self-hosted, with optional end-to-end encryption. It keeps the simplicity of IRC, and it adds the functions that most people use each day.

Downloads Source code

Post is at the start of its development. Do not use it for real conversations.

Between IRC and Telegram

IRC is simple and clear, but it is old. Telegram has many functions, but it became too complex. Post is between them.

  • Simple first

    Post has few concepts: server, channel, direct message, message, and user. Each task has one good method.

  • Security is always on

    Each connection uses TLS. A chat can have end-to-end encryption. Such a chat is a sealed chat.

  • The truth

    Each chat shows who can read it. Post has no telemetry and no advertisements.

  • Your server, your data

    Each server is independent, and any person can operate one. An account has no password, no email address, and no telephone number.

  • Open

    The protocol is public. Its messages are JSON text that a person can read. Each program that obeys the protocol can connect.

  • Fast and calm

    Text comes first. Only a direct message or a mention causes a notification. Post has no read receipts.

  • For all people

    A user can do each task with the keyboard. The interface has English and Latin American Spanish text.

  • An end

    Version 1.0 contains all the functions of Post. After that, the project corrects errors and keeps Post secure.

Read the design philosophy.

The plan for version 1.0

Version 1.0 contains these functions. Most of them do not exist yet.

  • Channels, direct messages, and message history.
  • Replies, reactions, mentions, files, images, and search.
  • Voice channels.
  • Sealed chats with end-to-end encryption.
  • Roles and moderation tools for a community.
  • Bots, webhooks, and a public protocol.

The roadmap gives the sequence of the versions. The changelog tells what each version can do.

What Post will not have

A product stays simple only if it refuses functions.

  • Stickers, GIF search, and stories.
  • Payments, mini applications, and advertisements.
  • A feed that an algorithm sorts.
  • Read receipts and "last seen" times.

The philosophy gives the full list.
