Una aplicación de chat moderna con el espíritu de IRC.

Post es simple, abierta y autoalojada, con cifrado de extremo a extremo opcional. Conserva la simplicidad de IRC y agrega las funciones que la mayoría de las personas usa todos los días.

Descargas Código fuente

Post está al inicio de su desarrollo. No lo uses para conversaciones reales.

Entre IRC y Telegram

IRC es simple y claro, pero es antiguo. Telegram tiene muchas funciones, pero se volvió demasiado complejo. Post está entre los dos.

  • Primero, lo simple

    Post tiene pocos conceptos: servidor, canal, mensaje directo, mensaje y usuario. Cada tarea tiene un solo método bueno.

  • La seguridad siempre está activa

    Cada conexión usa TLS. Un chat puede tener cifrado de extremo a extremo. Ese chat es un chat sellado.

  • La verdad

    Cada chat muestra quién puede leerlo. Post no tiene telemetría ni publicidad.

  • Tu servidor, tus datos

    Cada servidor es independiente y cualquier persona puede operar uno. Una cuenta no tiene contraseña, correo electrónico ni número de teléfono.

  • Abierto

    El protocolo es público. Sus mensajes son texto JSON que una persona puede leer. Cualquier programa que respete el protocolo puede conectarse.

  • Rápido y tranquilo

    El texto va primero. Solo un mensaje directo o una mención genera una notificación. Post no tiene confirmaciones de lectura.

  • Para todas las personas

    Puedes hacer cada tarea con el teclado. La interfaz tiene texto en inglés y en español de Latinoamérica.

  • Un final

    La versión 1.0 contiene todas las funciones de Post. Después, el proyecto corrige errores y mantiene Post seguro.

Lee la filosofía de diseño (en inglés).

El plan para la versión 1.0

La versión 1.0 contiene estas funciones. La mayoría todavía no existe.

  • Canales, mensajes directos e historial de mensajes.
  • Respuestas, reacciones, menciones, archivos, imágenes y búsqueda.
  • Canales de voz.
  • Chats sellados con cifrado de extremo a extremo.
  • Roles y herramientas de moderación para una comunidad.
  • Bots, webhooks y un protocolo público.

La hoja de ruta da el orden de las versiones. El registro de cambios dice qué puede hacer cada versión. Los dos documentos están en inglés.

Lo que Post no tendrá

Un producto solo se mantiene simple si rechaza funciones.

  • Stickers, búsqueda de GIF e historias.
  • Pagos, miniaplicaciones y publicidad.
  • Un feed ordenado por un algoritmo.
  • Confirmaciones de lectura y horas de «última conexión».

La filosofía da la lista completa (en inglés).
