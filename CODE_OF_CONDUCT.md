# Code of conduct

This code applies to all places of the Post project: the issues, the pull requests, the reports, and each other project channel.

## Our aim

All people are welcome in the Post project. We want each person to be able to take part safely and with respect.

## What we expect

- Be kind and patient.
- Respect a person who has a different opinion or a different level of experience.
- Speak about the work, not about the person.
- Accept correction, and give correction politely.
- Use words that all people can understand.

## What we do not permit

- Insults, threats, and attacks on a person.
- Harassment of any type, in public or in private.
- Sexual language or sexual images.
- Statements against a person because of race, sex, gender, age, religion, nationality, disability, or orientation.
- The publication of private data of a different person without permission.

## If a problem occurs

Tell a maintainer of the project in an issue. If you cannot write in public, use the "Report content" function of GitHub on the comment or the issue.

A maintainer examines each report.

## What a maintainer can do

A maintainer can remove a comment, a commit, or an issue that breaks this code. A maintainer can also remove a person from the project, for a time or permanently.
