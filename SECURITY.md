# Security

## State of Post

Post is at the start of its development. Version 0.1 has no accounts and no encryption, and it connects only to a server on the same computer. Do not use it for real conversations.

No independent audit of Post exists. The [threat model](docs/threat-model.md) tells what Post protects and what it does not protect.

## How to report a security problem

Do not open a public issue for a security problem.

1. Open the [Security page](https://github.com/collide2954/post/security) of the repository.
2. Select **Report a vulnerability**.
3. Describe the problem and the steps that show it.

Only the maintainers of the project can read your report. The report stays private until a correction exists (decision record D-162).

## What to expect

- A maintainer answers your report.
- The project corrects a real problem as quickly as possible.
- The changelog tells about the correction. The project gives your name if you want that.

## Supported versions

During the 0.x versions, only the newest version gets security corrections.
